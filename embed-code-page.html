Proportion Plinko for Google Sites

Copy this code and paste it into an Embed box on your Google Site. Students play it on the site page.

About 774 KB of code. It includes all 33 questions.

  1. Open your Google Site and go to the page where the game should go.
  2. On the right, under Insert, click Embed.
  3. Choose the Embed code tab (not "By URL"), paste with Ctrl+V, and click Next, then Insert.
  4. Drag the embed's corner to make it as big as possible: full page width and very tall. Students can also scroll inside it.
  5. Click Publish, then open the site on a student account to test it.

If Google Sites says the code is too long, tell Claude and ask for a split version with fewer questions per embed.
